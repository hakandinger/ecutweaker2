# EcuTweaker 2 - Flutter Mobile App

## Project Overview

EcuTweaker 2 is a mobile application developed with Flutter for diagnosing, monitoring, and configuring automotive Electronic Control Units (ECUs) over CAN networks. The app is designed for car enthusiasts, mechanics, and engineers who need to access and modify ECU parameters directly from their mobile devices.

With EcuTweaker 2, users can:

- Connect to vehicle ECUs via Bluetooth or USB serial interfaces
- Read and monitor real-time data and diagnostic trouble codes (DTCs)
- Modify configuration parameters and settings
- Visualize ECU data with dynamic, auto-generated user interfaces
- Benefit from a modern, user-friendly design with dark mode support

The project aims to simplify ECU diagnostics and configuration, making advanced automotive tasks accessible on both iOS and Android platforms.

## 🚀 Features

- 📱 **Fully Mobile**: Supports both iOS and Android
- 🔌 **Multiple Connections**: Bluetooth and USB serial connectivity
- 📊 **Dynamic UI**: Automatically generates screens from JSON layout files
- ⚡ **Real-Time Monitoring**: Live ECU parameter tracking
- 🎨 **Modern Design**: Built with Material Design 3 for a modern interface
- 🌙 **Dark Mode**: Dark theme support
